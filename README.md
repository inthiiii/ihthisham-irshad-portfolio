# M. Ihthisham Irshad — Portfolio

One-page portfolio for M. Ihthisham Irshad, positioned as an AI / Machine Learning Developer working across agentic AI, multimodal systems, and data intelligence.

## Stack

- Next.js 16 and TypeScript
- Tailwind CSS 4
- Framer Motion
- Vercel-ready static rendering

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
npm run build
```

The site includes responsive layouts, reduced-motion handling, semantic project dialogs, SEO metadata, structured data, optimized project artwork, and locally hosted CV/certificate assets.
